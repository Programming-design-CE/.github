## 프로젝트 설명

**단웅의 할일**는 팀 프로젝트와 개인 할 일을 함께 관리할 수 있는 캐릭터 기반 To-Do 서비스입니다.
사용자는 공동 할일을 생성하고 팀원들과 업무를 나누어 진행할 수 있으며, 할일을 완료하면 마늘 보상을 획득하고 이를 통해 아이템을 구매해 캐릭터를 꾸밀 수 있습니다.

## ✨ 핵심 기능

| 구분 | 핵심 기능 | 설명 |
| --- | --- | --- |
| 👤 회원 | 회원가입 및 로그인 | 사용자는 계정을 생성하고 로그인하여 서비스를 이용할 수 있습니다. |
| 👥 친구 | 친구 검색 / 요청 / 승인 / 거절 | 닉네임으로 친구를 검색하고 친구 요청을 보내거나 받은 요청을 처리할 수 있습니다. |
| ✅ 공동 할일 | 공동할일 그룹 생성 | 팀 프로젝트 그룹을 생성하고 참가자를 초대할 수 있습니다. |
| ✅ 공동 할일 | 그룹별 할일 관리 | 그룹별 할일을 생성, 수정, 삭제하고 상세 내용을 조회할 수 있습니다. |
| 🙋 개인 할일 | 개인 담당 할일 조회 | 자신에게 배정된 할일 목록을 모아 확인할 수 있습니다. |
| 🎁 보상 | 할일 완료 보상 | 할일 완료 시 마늘을 보상으로 지급받고 기여도에 반영할 수 있습니다. |
| 🧄 상점 | 마늘 상점 아이템 구매 | 획득한 마늘을 사용하여 상점에서 아이템을 구매할 수 있습니다. |
| 👕 옷장 | 보유 아이템 조회 / 캐릭터 적용 | 구매한 아이템을 조회하고 단웅이 캐릭터에게 적용할 수 있습니다. |
| 📝 메모 | 개인 메모장 / 그룹 메모장 | 개인 메모와 그룹별 메모를 작성하고 관리할 수 있습니다. |
| 📅 캘린더 | 공동할일 캘린더 조회 | 그룹에 등록된 할일을 캘린더 형태로 확인할 수 있습니다. |
| 📁 파일 | 파일 업로드 / 폴더 관리 | 그룹 프로젝트와 관련된 파일을 업로드하고 폴더로 관리할 수 있습니다. |
